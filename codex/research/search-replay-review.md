The five core paper IDs/titles above agree with the supplied index. Go-Exploit's arXiv record explicitly identifies AAMAS2023; PER's arXiv record identifies ICLR2016, so “2015” is its preprint date. KataGo's GitHub notes are implementation documentation, not a separate peer-reviewed paper.

The dossier's explicit warning is correct: [arXiv2202.11772](https://arxiv.org/abs/2202.11772) is **Discovering Multiple and Diverse Directions for Cognitive Image Properties**, an unrelated GAN/image-editing paper. It is not Gumbel AlphaZero. Use OpenReview `bERaNdoegnO`. Direct OpenReview requests returned a browser challenge during this review; the indexed original paper and the authors' `mctx` source independently confirm the identity and algorithm. This is an access limitation, not evidence that the official URL is bogus.

Spot-checks of [2301.11857](https://arxiv.org/abs/2301.11857), [2602.20809](https://arxiv.org/abs/2602.20809), [2607.08984](https://arxiv.org/abs/2607.08984), and [2609.37447](https://arxiv.org/abs/2609.37447) returned the titles claimed by the dossier. ## Existing pipeline: what is already done and where the gap remains

- `actor.py` repeatedly plays the current best and admits runtime CPU/self-play arguments from `cpu_budget.json`. It starts ordinary games, not Go-Exploit restarts.
- `learner.py` reads completed newest self-play directories and all `data/ext_*` directories into one learner. Current coordination states a roughly50k-fresh-position trigger,3000 training steps, and a roughly600k-position window. Keep this single owner/process.
- `train.py` already fixes external rows at `ext_frac=.04`, supports `has_value`, and masks the outcome-derived length auxiliary with that mask. `q_valid` independently controls Q mixing and Q auxiliary. Thus `has_value=False` alone does **not** disable Q-aux supervision.
- `research_ext.py` already creates `ext_site_v1_rs` from all1,965 site rows with GEN02,800 simulations, no root noise. Its rows have `has_pol=True`, `has_value=False`, `q_valid=True`. Policy re-search therefore supplements the original true-outcome rows rather than recounting their outcomes in the value loss.
- Re-search stores `idx[:128]` and corresponding probabilities. Current normal branching is small, but production admission should assert that every legal action fits and targets sum to1. Dropping any legal index from the policy denominator is a different operation from assigning it zero target probability. A128-entry overflow is a potential guard condition, not a demonstrated current failure.
- The new output manifest currently records model path and simulation budget but no model/source digest or per-row immutable provenance. The repair receipt should bind the exact GEN02 hash, original game/ply, observation hash, source-target hash and proof file; do not depend on a path called “current.” This is a small data receipt addition, not a new acceptance workflow.

The underlying referee discards redirected-attack children (`cache=False`), so simply raising the same PUCT teacher from100 to800 visits does not guarantee deeper continuation on those edges. Exact proof labels can supply information that repeated heuristic leaf evaluation misses. Do not patch the server or its local comparison copy to make a teacher result appear to be tournament behavior.

## Bounded certificate-guided policy repair

Current inspected loss evidence is bound to GEN02 SHA256 `579d3ec01da7328dc706003b8dcc5eba357bb74902252187e45633ca0595a9a0` in `codex/matches/site-gen02-loss-mining-v1.json`. The report records still-unsafe GEN02 choices at7525/action26,8079/action30,8185/action42,8443/action30. At7658/action56 every final action allows an opponent terminal win, but preceding action55 has two safe starts. Won game8228/action35 also misses a witnessed immediate own-turn win. These are actual supplied game contexts, not synthetic assumptions. This review did not re-run their certificates; independent verification is owned by the assigned worker.

For one observation, let L be its complete legal action set. Let W contain first actions independently certified to win before the current player's turn ends. Let U contain actions independently certified to allow an opponent terminal win on the immediately following turn, taking account of any remaining own action. Set S=L minus U.

1. If W is nonempty, restrict the existing800-search target to W and renormalize. If it assigned zero total mass to W, use a declared uniform distribution over W (or over the verified subset of winning witnesses). The positive certificate supports a +1 value for the current player, but policy-only repair can conservatively leave original true-outcome supervision separate.
2. Otherwise, if S is nonempty, restrict the target to S and renormalize. If it has zero mass on S, use uniform S as a **safety preference**. S is not a set of proved winning or proved optimal actions. Keep `has_value=False`; do not manufacture +1 or reinterpret the old game's outcome as a counterfactual continuation outcome.
3. If S is empty, do not normalize an empty mask or manufacture a good target. Keep the original outcome evidence; skip this row's safety-policy repair. For7658 this means use the preceding action55 safe-start certificate rather than treating action56 as an avoidable final mistake.
4. Keep **all L** in `pidx`, including rejected actions with zero `pval`. The existing CE gathers `pidx` and softmaxes across that support; removing U from `pidx` would prevent learning to suppress U. Preserve a normalized target, finite values and exact canonical from/to mapping.
5. New proof-repaired rows should normally set `q_valid=False`, because their inherited approximate root Q did not become exact when the policy changed. Otherwise Q auxiliary remains active despite `has_value=False`. This does not require changing existing re-search rows if Opus deliberately retains their approximate Q auxiliary elsewhere.
6. Replace/overlay only matching derived re-search row versions, or supersede them with an explicit manifest. Do not silently mix conflicting old and repaired policy labels for the exact same observation. Raw site protocols and true outcome rows remain intact. Use the same game group for all original, re-searched, repaired and D4-related rows.

Two-action quantifiers matter. For own first-action starts with two actions remaining, a winning certificate needs **there exists first own action, there exists second own action, terminal own win**. An unsafe first-action certificate needs **for every legal remaining own continuation, the opponent has a terminal winning continuation**. “This one recorded second action loses” is insufficient to condemn its preceding first action. Opponent turns also use two consecutive MAX actions from the opponent's viewpoint. Negate value only on an actual team change, never after every action. Immediate Kernel capture preempts bare-Kernel adjudication and firewall; guards redirect attacks while the attacker stays; terminal certificates must use those exact transitions.

For general defenses, absence of an opponent one-turn win proves only the stated bounded safety property. It does not prove an eventual win or draw. The actual game's no-draw/tiebreak rule does not turn an unfinished finite search into an outcome oracle.

### Priority, cost, risk and the deciding evidence

Apply repair first to the existing six hard loss observations and one missed-win observation. This requires no new800-simulation pass. The proposed projection costs linear time in the existing legal target arrays; independent certificate verification has a bounded one-/two-turn tree cost and is already assigned. Do not estimate measured seconds from these asymptotic costs.

If those repaired rows remain too dilute, use capped priority **inside** the existing4% external share: retain a uniform component, add proof-conflict/policy-surprise priority, and cap each row at roughly3× its uniform frequency as an initial engineering bound. No source establishes3× as optimal. Avoid a new large fixed hard-case batch share that repeats seven observations thousands of times. Keep at least half the source sampling mass uniform, and do not boost the same board independently for each equivalent D4 transform or replay version.

Measure whether existing800-search targets assign any probability to U or omit W before claiming repair was necessary. On new candidate GEN03+, inspect rejected-action probability, winning-witness recall and the exact bounded safety property for these known contexts. Those are training diagnostics, not held-out strength. Hold new games/motif families out by whole game; existing held-out synthetic48 states remain TEST_ONLY. Final strength still requires the unchanged100-simulation referee against the GEN02 baseline, with swapped colors and fresh seeds through Opus's shared gate. Do not introduce model experiments from this research task.

Main risks are proof incompleteness, wrong same-player quantifiers, leaking true outcomes into unknown counterfactual values, conflicting duplicate targets, stale proof/model provenance, and oversampling a tiny handful of site states. More paper mechanisms do not address these as directly as the bounded verified support repair.
